# 物理譜（Physica Atlas）

繁體中文的大學普通物理知識圖譜。第一版以微積分制普通物理為主線，把課程拆成可評量的概念節點，再用必要／建議先修關係連成可探索的學習網路。

## 線上瀏覽

[開啟物理譜：普通物理知識圖譜](https://changyi123456.github.io/ordinary-physics-atlas/)

## 內容設計

- 已提供可直接雙擊開啟、無需伺服器的單一 HTML：`output/ordinary-physics-atlas.html`。
- 範圍涵蓋物理方法、運動學、動力學、能量與動量、轉動與流體、振動與波、熱學、電學、磁學、光學、相對論與量子／原子／核物理。
- 每個節點包含原創中文摘要、KaTeX 排版與可展開的 LaTeX 原始碼、掌握證據、常見迷思、來源索引與硬／軟先修。
- 圖譜採固定且可重現的三維座標，不在載入時進行不穩定的力導向模擬。
- Canvas 提供立體球形節點、旋轉、平移、縮放滑桿、選取與先修追溯；另有可鍵盤操作的搜尋與完整列表。
- `?topic=<stable-id>` 可直接連到指定概念。

## 研究與來源

完整方法、來源用途與授權邊界見 [RESEARCH.md](./RESEARCH.md)。外部教材與研究用於範圍、深度和概念瓶頸的交叉查核；本站不重製教材段落、圖像或受限制的正式評量題目。

## 本機開發

```bash
npm run dev
npm run build
npm run offline
```

`npm run offline` 會重新產生單一 HTML；字型、KaTeX、CSS、JavaScript 與 185 個概念資料都會內嵌，因此離線也能完整開啟。
